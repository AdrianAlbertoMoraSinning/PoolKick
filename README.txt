POOLKICK FAVICON PACKAGE

Copy every file inside /public into the PoolKick /public directory.
Replace the project's root index.html with the included index.html.

- favicon.svg
- favicon.ico (16/32/48/64/128/256)
- favicon-16x16.png
- favicon-32x32.png
- favicon-48x48.png
- apple-touch-icon.png (180x180)
- android-chrome-192x192.png
- android-chrome-512x512.png
- maskable-icon-512x512.png
- mstile-150x150.png
- safari-pinned-tab.svg
- site.webmanifest
- browserconfig.xml
- updated index.html

After uploading to GitHub, Netlify should auto-deploy. If the old favicon remains visible,
hard-refresh or clear the browser favicon cache.
